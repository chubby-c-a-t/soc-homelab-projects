# SOC Homelab Projects

This repository contains practical SOC homelab projects created to develop my skills in security monitoring, KQL, threat detection, incident investigation and response.

Unlike my investigations using the TryHackMe and LetsDefend simulation platforms, these projects document environments and detection workflows that I have configured and tested myself. The primary purpose is to gain practical experience while preparing for security operations roles and the Microsoft SC-200 exam.

---

## Microsoft Sentinel Homelab

This homelab uses a local Windows 11 LTSC virtual machine connected to Microsoft Sentinel through Azure Arc and Azure Monitor Agent.
